📊 Sales Analysis Dashboard – Branch and Customer Insights
📝 Project Overview

This project delivers a comprehensive sales analysis across three branches, three cities, and multiple customer segments.
Analysis was performed using Microsoft Excel with pivot tables, charts, and slicers to provide actionable insights for business decisions.

📂 Data Description

The dataset contains the following columns:

1.	3 Branchs: A, B, C
2.	3 Cities: Yangon, Naypyitaw, Mandalay
3.	Customer Types: Membership, Normal
4.	Gender: Male, Female
5.	Product Categories:
Health & Beauty
Electronic Accessories
Home & Lifestyle
Sports & Travel
Fashion Accessories
Food & Beverages
6.	Tax: 5% applied to each product
7.	Payment Type: E-wallet, Cash, Credit Card
8.	Sales Metrics: Quantity sold, Total sales amount


🔍 Key Findings
Branch-wise Analysis
1.	Branch C achieved the highest sales: 110,569
2.	Branch B recorded the lowest sales: 106,200
3.	Top-selling product by branch:
4.	Branch C: Food & Beverages (23,767)
5.	Branch A: Home & Lifestyle (22,417)

Gender-wise Analysis
1.	Female customers purchase slightly more than male customers overall
2.	Exception: In Food & Beverages, male customers slightly exceed female customers

City-wise Analysis
1.	Highest sales: Naypyitaw (61,685) – Gross income: 2,537
2.	Lowest sales: Mandalay (52,928) – Gross income: 2,520

Payment Type Analysis
1.	Cash is the most preferred payment method overall
2.	In Mandalay, Credit Card usage surpasses other methods

Customer Type Analysis
1.	Membership users outnumber normal users
2.	Most membership users are concentrated in Naypyitaw

📊 Dashboard Features

The dashboard includes:
1.	Key Performance Indicators (KPIs):
2.	Quantity sold
3.	Tax paid
4.	Unit price paid
5.	Total sales amount
6.	Pivot Tables for each major analysis dimension:
7.	Branch, City, Gender, Product, Payment Type, Customer Type
8.	Charts and Graphs for trend visualization and comparisons
9.	Slicers for dynamic and interactive filtering





🛠 Tools Used
Microsoft Excel (Pivot Tables, Charts, Slicers, Formulas)

🎯 Insights & Business Impact
1.	Identified Branch C as top-performing branch with Food & Beverages leading sales
2.	Uncovered customer behavior trends, including membership dominance and gender preferences
3.	Highlighted city-wise sales performance to optimize marketing efforts
4.	Analyzed payment trends to inform financial operations and payment method strategies
